В столбце «Медиана времени по замкам» взята медиана 45 индивидуальных медиан,
каждая из которых получена из пяти повторов после одного прогрева.
Сумма медиан не является медианой времени полного прохода каталога.

По числу действий относительно UnlockMyLoot: **5 выигрышей, 40 равенств,
0 проигрышей**. Разных выбранных пластин столько же на каждом из 45 входов.
Сдвигов больше на 6 входах, столько же на 39. Новый поиск быстрее стороннего
по индивидуальной медиане на всех 45 входах в этом запуске; максимум индивидуальных
медиан нового поиска — 7,302 мс. Это наблюдение, не универсальная гарантия скорости.

Исходный BFS нашего проекта уже находил минимум действий на этих входах.

с другим приоритетом: его текущий режим сначала минимизирует сдвиги, наш — действия.
Глобальный минимум U и C среди равных по A решений не заявляется.

## Воспроизведение

Требуется Node.js 20+. Сторонний checkout хранится отдельно; его solver не включён
в наш репозиторий.

```bash
git clone https://github.com/Marcus-Rise/gothic-lock-solver.git
git -C gothic-lock-solver checkout 6b1cfbc13bcec68f609d45d5dc97504dd84f1760
git clone https://github.com/1h8s/unlockmyloot.git
git -C unlockmyloot checkout eee0bf50ebcb7fffd2b47954fd76bb015854e365
cd gothic-lock-solver
node --test
node scripts/build-browser.mjs --check
node scripts/benchmark.mjs --reference ../unlockmyloot --repetitions 5 --warmups 1 --output-dir docs/benchmarks
```

Отчёт содержит версии Node/V8, CPU/ОС, хэши входов и исходников, порядок измерений,
границы таймера и все отдельные замеры. Все реализации исполнялись в одном
Node.js runtime; проверенная функция UnlockMyLoot компилировалась без изменений
в том же JS-контексте. Проверка путей, копирование входов и нормализация ответов
исключены из измерения. GC естественный, без принудительного запуска.

## Границы проверки

Проверки подтвердили независимое воспроизведение путей, минимум действий через
точный BFS, детерминированность, отсутствие изменения входов и сохранение исходного
порядка BFS. Математическое ядро и сценарий измерений прошли независимый review
без существенных замечаний.

Времена относятся к Node.js на указанной машине. Они не измеряют браузер, Worker,
телефон или время действий игрока. Изолированные проверки ESM и готового classic
script прошли без Node/DOM-зависимостей. Попытка проверки HTML в настоящем браузере
не смогла загрузить локальный сервер среды (`net::ERR_BLOCKED_BY_CLIENT`), поэтому
реальный браузерный запуск и Worker остаются отдельной ручной проверкой.
